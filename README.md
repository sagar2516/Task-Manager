# Task-Manager
# 📝 Task Manager Web App

A simple and responsive task manager built using HTML, CSS, and JavaScript. It allows users to add, complete, and delete tasks, with data persistence via `localStorage`.

---

## 🚀 Features

- ✅ Add new tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Tasks persist across page reloads (localStorage)
- ✅ Dynamic DOM rendering
- ✅ Empty state message when no tasks exist
- ✅ Basic input validation
- ✅ Smooth transitions for UI updates
- ✅ Responsive layout
